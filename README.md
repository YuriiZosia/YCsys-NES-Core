## 📖 Про проєкт

**YCsys-NES-Core** — це високоточний (cycle-accurate) емулятор консолі Nintendo Entertainment System (NES / Famicom), написаний з нуля на чистому C++. 

Мета проєкту полягала не просто у створенні програми, що запускає ігри, а в досконалій цифровій реставрації оригінального апаратного забезпечення. Ядро процесора MOS 6502 відтворено з точністю до такту і проходить авторитарний стрес-тест `nestest.nes` на 100%.

## ✨ Головні можливості

### 🧠 Апаратна точність (Core)
* **100% Cycle-Accurate CPU:** Ідеальна емуляція MOS 6502, включаючи всі нелегальні (undocumented) опкоди та апаратні баги (напр., баг перетину сторінок при JMP).
* **Точний PPU (Відеочіп):** Повна підтримка мультиплексування екрана, Sprite 0 Hit, маскування країв екрана та спрайтів 8x16.
* **Open Bus Architecture:** Точна емуляція "сміттєвих" даних на шині контролера для обходу антипіратського захисту в іграх (напр., *Bomberman*).

### 📺 Інтерфейс та Досвід (UX/UI)
* **CRT Boot Animation:** Унікальна заставка при запуску, що імітує розігрів кінескопа старого телевізора.
* **Native ROM Selector:** Зручний та надійний вибір ігор через нативне вікно Windows API.
* **Save States (Швидкі збереження):** Можливість миттєво зберегти та завантажити стан консолі (пам'ять, регістри, таймінги) в будь-який момент гри.
* **Battery RAM:** Автоматичне створення файлів `.sav` для ігор, що підтримують збереження на картридж (напр., *The Legend of Zelda*).

### 🎵 Аудіо (APU)
* **Автентичний синтез:** Підтримка каналів Pulse (1 та 2), Triangle та Noise з апаратними огинаючими (Envelopes) та ефектами ковзання (Sweep).
* **Нелінійне мікшування:** Точний розрахунок вихідного сигналу за оригінальною математичною моделлю NES.
* **Двополюсний Low-Pass Filter (LPF):** Інтегрований фільтр низьких частот, що зрізає цифровий аліасинг і відтворює теплий, "ламповий" звук класичних паперових динаміків (ідеально для сучасних навушників).

| **Завантажити гру (Load State)**| `F7` |

## 💾 Підтримувані Мапери (Картриджі)

Емулятор підтримує динамічне завантаження маперів. Наразі реалізовано:

* **Mapper 000 (NROM):** Базовий мапер (*Super Mario Bros., Donkey Kong, Pac-Man*).
* **Mapper 001 (MMC1):** Складні ігри зі збереженнями та динамічним скролінгом (*The Legend of Zelda, Zelda II, Metroid*).
* **Mapper 002 (UxROM):** Ігри з перемиканням PRG банків (*Castlevania, Contra, Duck Tales*).
* **Mapper 003 (CNROM):** Перемикання CHR графіки (*Adventure Island, Cybernoid*).
* **Mapper 004 (MMC3):** Просунутий чіп з IRQ перериваннями екрана (*Super Mario Bros. 3, Batman, Chip 'n Dale*).

## 🛠️ Як зібрати проєкт (Build)

1. Відкрийте рішення у **Visual Studio 2026** (або новіше).
2. Переконайтеся, що бібліотека **SDL2** підключена до проєкту (рекомендується через NuGet Package Manager).
3. Встановіть платформу `x64` або `x86` та режим `Release` для максимальної продуктивності.
4. Скомпілюйте проєкт.
5. Запустіть `.exe` файл, насолоджуйтеся CRT-заставкою та виберіть `.nes` ROM-файл у діалоговому вікні.
